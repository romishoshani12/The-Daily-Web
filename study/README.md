# אתר תרגול להגנה — The Daily Web

אתר לימוד ותרגול לפני ההגנה. הוא כולל:

- הסבר מאפס למי שלא מתכנת
- מה הבוחן בודק בפועל
- שיעור מלא על הפרויקט
- הסבר של הקוד שורה אחרי שורה
- מדריך הדגמה
- מבחן של 62 שאלות עם תשובות

האתר נמצא רק בענף `ui-checker`. הוא לא חלק מקוד האתר, והשרת לא מגיש אותו.
