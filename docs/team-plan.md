# פיתוח אתר החדשות בצוות

רומי מקימה את החוזים ונקודות ההרחבה. אחר כך התשתית עצמה מתפצלת לחמישה ענפים: רומי — זהויות ואבטחה; נופר — נכסי תמונה; בר — מודלי תוכן וכלי דפדפן; רועי — עיצוב משותף; בן — ולידציה ותחתית האתר.

אחרי מיזוג התשתיות מחברים את המודולים המשותפים, כולל API לרשימת כתבות. רק אז יוצרים team-base וחמישה ענפי פיצ׳רים: התחברות, פיד, קוראים ותגובות, סביבת כתב, סביבת עורך. כל בעל פיצ׳ר אחראי ל־HTML/EJS, ל־CSS, ל־JavaScript ולשרת שלו.

חיבור ה־autosave מתבצע בענף הכתב. פעולות סקירת העורך מתחברות אליו רק לאחר מיזוג הפיצ׳רים. בורר הכתבות במסך הנתונים משתמש ב־API שכבר נמצא בבסיס, ולא מצריך משיכה מענף הכתב.

תכנית עבודה יחסית: שבוע ראשון לתשתיות ולחיבורן; שבוע שני לפיצ׳רים במקביל; שבוע שלישי להשלמה, מיזוג ובדיקות; שבוע רביעי לפי הצורך לתיקונים ותיעוד. זהו תכנון קדימה, לא תאריכי ביצוע ולא היסטוריה של עבודה שכבר נעשתה.

המספור, הוראות ההעתקה והבעלות המדויקת לכל קומיט נמצאים בחבילת הקומיטים הנלווית, ב־START-HERE.md וב־COMMIT.md של כל תיקייה. הם המקור לסדר העבודה; אין להסתמך על מספור מחבילות קודמות. מספר קומיטים אינו מדד שעות, ויש לאזן לימוד ובדיקות לפי המאמץ בפועל.
