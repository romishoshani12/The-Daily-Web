# בדיקת אתר החדשות

## בדיקות מקומיות

scripts/check.js בודק תחביר JavaScript ורינדור EJS. tests/weather.test.js ו־tests/workflow.test.js בודקים לוגיקה עם נתונים נשלטים. tests/integration.test.js מפעיל HTTP ו־MongoDB אמיתיים, ורק כאשר TEST_MONGODB_URI מוגדר. הוא משתמש במסד בדיקה ייעודי ומוחק אותו בניקוי; אין להגדיר כתובת מסד עם נתונים שרוצים לשמור.

ללא משתנה מסד הבדיקה, תרחיש HTTP מדולג. דילוג אינו אישור שהתנהגות מול מסד נבדקה. תצוגת preview היא עיצוב עם נתוני דוגמה ואינה מערכת התחברות אמיתית.

## בדיקות תפעול לפני שחרור

בדקו כניסה בשני התפקידים, בעלות על טיוטה, שמירה ושחזור, החזרה ואישור, שימור הגרסה הציבורית, תגובות, חיפוש, גרף וניהול משתמשים. בדקו גם תצוגת מובייל ושגיאות רשת. אין להסיק מהבדיקות המקומיות זמינות של ספק מזג האוויר או יכולת לעמוד בעומס שלא נמדד.
