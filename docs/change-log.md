# תיקונים ושיפורים

העבודה מבוססת על `the-daily-web(3).zip` ועל מסמך הדרישות שהועלו בשיחה. העיצוב המקורי, האיורים המקומיים והטכנולוגיות נשמרו: Node.js, Express, MongoDB/Mongoose, EJS, HTML, CSS ו־Vanilla JavaScript. לא נוספה תלות להרצת המערכת. גרף הנתונים נשאר Canvas.

| בקשה | התוצאה | מקום עיקרי |
|---|---|---|
| 1. הסרת הודעת הגבלת תגובות הקבועה | ההנחיה הוסרה מהטופס; השרת מחזיר 429 והודעה בעת חריגה, והטופס מציג אותה | article.ejs, comments.js |
| 2. תחתית האתר | ״מערכת חדשות עצמאית · אתר חדשות״ | footer.ejs |
| 3. כותרת אזור התגובות | ״תגובות הקוראים״ נמצאת מעל ״השיחה ממשיכה כאן״ | article.ejs, article.css |
| 4. ניסוח המותג | ״חדשות. אנשים. נקודות מבט.״ | head.ejs |
| 5. קישור לתגובות | ״לתגובות״, עם עוגן לכותרת האזור | article.ejs |
| 6. הסרת בחירת תפקיד מהניווט | אורח רואה כניסת צוות בלבד; תפקיד נקבע מה־Session ומרשומת המשתמש | head.ejs, auth.js, security.js |
| 7. הגשה מחדש | בכתבה שהוחזרה מופיע ״הגשה מחדש לאחר תיקון״ גם לאחר שמירה | write.ejs, write.js |
| 8. השוואה לעורך בלבד | תבנית ההשוואה נשלחת רק לעורך וכוללת גם את התמונה הציבורית. GET העבודה של כתב אינו מחזיר published | published-comparison.ejs, reporter.js |
| 9. המשך עריכה ללא החלפת משתמש | תוקנה הסיבה בתצוגת העיצוב: הוסרה התחזות לפי הנתיב. במערכת המלאה נבדקו זהות העורך, שמירה, רענון ובעלות הכתבה | preview.js, integration.test.js |

## בעיות נוספות שתוקנו

- כפתור הגשה בעדכון של כתבה שפורסמה מופעל רק לאחר עריכה ושמירה היוצרת טיוטה; אין שליחת מעבר סטטוס אסור בלחיצה רגילה.
- מספור גרסאות בגרף נשאר V2/V3 גם אם V1 מחוץ לטווח הזמן.
- חיפוש חדש בסטטיסטיקות מבטל תוצאה ישנה שעדיין בדרך.
- גרף ונתוני הטווח אינם כוללים רשומות צפייה עתידיות.
- דפדוף תגובות משתמש בסמן לפי זמן ומזהה, כך שמחיקה של תגובה קודמת אינה גורמת לדילוג על תגובה בהמשך.
- מספר עמוד ומצב כתבה ברשימת העבודה נבדקים בצד השרת. הרשימה אינה שולחת את גוף הטיוטה והגרסה הציבורית לכל כרטיס.
- נתיב API חסר מחזיר JSON עם 404; קיימים ערכי ברירת מחדל לתבנית שגיאה גם כשבקשה פגומה נכשלת לפני זיהוי המשתמש.
- מטמון מזג האוויר בודק גם תאריך ספק, דוחה זמן עתידי, שומר עותק תקף בעת כשל ספק וממתין 30 שניות לפני ניסיון חוזר. בדפדפן הנתון מוסר במועד שבו הוא נעשה ישן מ־15 דקות.
- בנתוני ההדגמה טיוטות עדכון שונות מהגרסה הציבורית, ונקודות הפרסום והצפייה עקביות עם זמן הפרסום הראשון.
- בקרי המשתמשים והסטטיסטיקות ותבנית ההשוואה הופרדו כדי לאפשר בעלות עצמאית על קבצים בענפים.

## עיצוב

הגוונים הירוקים והאיורים נשמרו. נוספו רקע נייר חמים, חותמת ״מבט מקרוב״, קווי מהדורה כפולים, מספור סיפורים, היררכיית כותרות ברורה יותר וקו התקדמות בקריאה. מצבי קטגוריה מסומנים גם עבור קוראי מסך. העיצוב אינו הוכחה לבלעדיות; הצוות צריך להתאים ולהבין את המימוש.
