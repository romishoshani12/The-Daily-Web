## מעבר למינימום

הגנת CSRF, הגבלת ניסיונות התחברות, revision למניעת דריסת טיוטה, מודרציית תגובות דרך המסך, השבתת משתמשים, טבלת נתוני גרף, חיווי שמירה ו־retry, מצבי ריק ושגיאה, קישור להעתקת כתבה, בדיקות קבלה ותצוגת עיצוב ללא התקנת מסד.

## דברים מנהליים שהקוד לא יכול לקיים במקומכם

כולם רשומים לאותו מרצה; כל אחד עובד בחשבון Git הפרטי ובמחשבו; כולם יודעים להסביר את כל הקוד; מגישים ZIP וקישור למאגר שניתן לצפות בו בזמן שנקבע; לא מעלים סודות למאגר; מבצעים הגנה על הגרסה שהוגשה בלבד. יש לבדוק את שעת ההגשה והמועד מול מסמך הקורס.

## תוספת לגרסה המתוקנת

השוואת גרסאות היא רכיב עורך בלבד. מפת תשעת התיקונים והתיקונים הנוספים נמצאת ב־change-log.md. תצוגת העיצוב אינה מסלול לבדיקת הרשאות; את כל מסלולי הצוות בודקים במערכת המלאה עם מסד ו־Session אמיתיים.
